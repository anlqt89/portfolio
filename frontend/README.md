## 🚀 The Portfolio: [anlam.app](https://anlam.app)
This repository contains my personal portfolio, designed with a "Terminal-Lab" aesthetic. It serves as a central hub for my technical projects, research, and engineering achievements.

### ⚡ Tech Stack
* **Frontend:** React, Tailwind CSS, Lucide Icons
* **Logic:** Custom Media Carousels, Intersection Observer for Sidebar Navigation
* **Styling:** Emerald-accented "Dark Mode" UI

---

## 🛠️ Core Engineering Features

### 🟢 Interactive Project Visualizer
Custom-built **Media Carousels** that display project workflows with a high-tech grid overlay. Each project includes a "Large Window" modal for deep technical dives.

### 📍 Scroll-Synced Navigation
Sidebar navigation that uses `IntersectionObserver` to track the user's viewport, providing real-time feedback on which project is being viewed.

### 📱 Performance First
Optimized for mobile-responsiveness and high-speed delivery via **Vercel**.
